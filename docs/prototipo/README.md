# Protótipos visuais

## Central de Operações — Premium v2

Arquivo de referência: [`../../index.html`](../../index.html) (cópia local; também pode estar em Downloads).

Protótipo estático **sem backend**: dados fictícios, drawer de pedido, filtros e export CSV demonstrativos. Use como north star de layout, tipografia (Inter), paleta verde `#176b56`, sidebar escura `#111c2b`, cartões com sombra suave e hierarquia (eyebrow → título → subtítulo).

O app Next.js (`src/app`) incorpora tokens e casca alinhados a este arquivo; blocos como fila de ações, tabela operacional completa e drawer lateral são evoluções futuras sobre dados reais.
